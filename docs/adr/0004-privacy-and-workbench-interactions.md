# ADR 0004：隐私与工作台交互

- 状态：已接受
- 日期：2026-09-22

## 决策

1. 提示词作为用户资产数据保存，但不写入普通运行日志；密钥、Authorization Header、签名和完整查询参数必须脱敏。
2. 任务成功后只更新并高亮瀑布流中的新资产，不自动打开详情，避免打断连续操作。
3. 图片详情第一版只显示一级直接来源，用户可通过来源图片继续查看上一层。
4. 设置页提供显式“测试连接”按钮；禁止在用户不知情时发起可能产生费用的完整生图请求。

## 结果

用户可以追溯正常资产的提示词和直接来源，同时不会因为日志或错误响应意外泄露密钥。工作台保持连续操作，复杂的来源树和服务商额度探测留待后续版本。
