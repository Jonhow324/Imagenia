# ADR 0003：模型、输入与界面边界

- 状态：已接受
- 日期：2026-09-22

## 决策

1. 第一版只使用后端配置的一个默认模型；前端不允许自由输入模型名称，也不提供模型选择器。
2. 生成表单只开放 `prompt`、`size`（square/landscape/portrait）和 `quality`（standard/high）。后端负责映射为提供商参数。
3. 任务错误使用稳定错误码、用户可理解的安全文案和仅写日志的详细信息三层结构。
4. 单 worker 串行执行；单个请求总超时 10 分钟；最多保留 50 个 `pending` 任务；超出时返回 `429`，不自动重试。
5. 资产列表使用 `created_at DESC, id DESC` 游标分页，每页默认 30 条，并支持收藏、类型筛选。
6. 未删除资产在详情中显示提示词；编辑结果显示自己的提示词并关联来源资产；删除后清除提示词和完整请求数据。
7. 编辑必须从已有资产详情进入，创建新的 `ImageAsset`，不覆盖原图。

## 结果

第一版的 UI 和提供商参数保持稳定，模型变更被隔离在后端配置和适配器中。限制参数和队列容量降低了复杂度，也避免将底层 API 细节直接暴露给用户。
