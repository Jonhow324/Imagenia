# ADR 0001：核心插件架构

- 状态：已接受
- 日期：2026-09-22

## 背景

Imagenia 是一个 QwenPaw 全栈图像插件。第一版需要生成、编辑、收藏、删除和瀑布流浏览，并在本地保存图片和任务状态。

## 决策

1. 使用 `ImageAsset` 表示生成或编辑得到的图片资产；编辑创建新资产，通过可空的 `source_asset_id` 记录来源，不覆盖原图。
2. 使用 SQLite 和显式 Repository 层，不引入 ORM。数据库变更通过版本化迁移脚本执行。
3. 使用 SQLite 持久化任务，并由插件生命周期管理单个后台 worker；第一版串行处理任务。
4. 第一版限制一个 `GenerationJob` 只产生一个 `ImageAsset`。
5. 前端通过短间隔轮询读取任务状态，暂不采用 SSE 或 WebSocket。
6. 图片使用 UUID 文件名并按年月组织；数据库保存相对路径，前端通过后端资源接口访问图片。
7. 删除来源图片时不级联删除编辑结果；保留后代资产并解除来源引用。
8. 前端采用单页面工作台：生成/编辑入口、任务状态、瀑布流和图片详情操作集中在同一页面。

## 结果

该方案减少了运行依赖和宿主集成复杂度，并为重启恢复、图片血缘和后续远程同步留下扩展点。代价是第一版只支持单 worker、轮询和单结果任务，吞吐量有限。
