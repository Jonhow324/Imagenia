# Domain Docs

This is a single-context repository.

## Before exploring

- Read `CONTEXT.md` at the repository root.
- Read the relevant ADRs under `docs/adr/` before modifying an area covered by those decisions.
- Use the domain vocabulary defined in `CONTEXT.md` in issue titles, specifications, tests, and implementation notes.
- If a change conflicts with an ADR, call out the conflict explicitly instead of silently overriding it.

## Layout

```text
/
├── CONTEXT.md
├── docs/
│   ├── adr/
│   └── agents/
└── src/   # when executable source is introduced
```
